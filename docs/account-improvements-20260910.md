# 고객·인플루언서 마이페이지 개선
운영 배포 전 검토 브랜치입니다.
- 관리자와 인플루언서의 정산 계산을 통일하고 조회 단계에서 본인·사이트를 제한합니다.
- 판매 기간 조회와 전체 기간 정산을 구분하며 확정액과 현재 계산액 차이를 안내합니다.
- 판매 기간·재고·공개 여부에 따라 공유 버튼을 제어하고 산지픽 호텔을 제외합니다.
- 일반 구매내역을 인플루언서 활동과 분리합니다.
- 주문 기간·상태·이전/다음 페이지, 상품별 주문 지정 리뷰를 제공합니다.
- 미운영 OS 구독과 중복 로그아웃을 제거합니다.
- 조회 실패를 빈 목록과 구분합니다.
- 선착순 명단은 서버에서 가림 처리하며 일반 인플루언서 전체 전화번호 복사를 제거합니다.
- 반품 행 잠금과 현재 상태 재검사, 중복 항목 검증, 환불 중 차단을 추가합니다.
- 고객 즉시 취소는 환불 잠금 내부에서도 발송 전 상태를 확인합니다.
- 공구 오픈 준비·정산 증빙 누락·확정액 차이 안내는 조회 시 자동 계산합니다. 외부 알림은 발송하지 않습니다.
검증: GitHub PR의 격리 DB 테스트와 기존 회귀 테스트 및 Next 빌드를 사용합니다.

## 후속 점검
- 주문 필터와 주문 지정 리뷰의 SQL 매개변수 표기 오류를 수정하고 실제 격리 DB 조회·저장으로 검증합니다.
- 인플루언서 공구 목록과 선착순 API는 현재 본인 지정 상품으로 한정합니다. 미지정 공용·타인·타 사이트 상품을 제외하며 본인 과거 정산은 유지합니다.
- 개인 일정이 없는 호텔 공구 카드는 숨깁니다.
- 리뷰 중복 저장은 DB 유일성 조건으로 방어하고 중복 안내를 반환합니다.
- 주문·호텔 페이지를 이동해도 조회 필터를 유지합니다.
- 선착순 조회에 새로고침·재시도·조회시각·타임아웃을 추가합니다.
- 리뷰 사진 파일 형식·8MB 제한을 미리 안내하고 미리보기 URL을 정리합니다.
