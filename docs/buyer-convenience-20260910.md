# 구매 편의성 개선 · 2026-09-10

## 구현
| 기능 | 동작 |
|---|---|
| 비회원 장바구니 | 블랜드픽·산지픽 호스트/사이트별 브라우저 보관, 7일 유효, 최대 30개 항목. 산지픽 옵션창에도 담기 버튼 추가. |
| 로그인 후 합치기 | 장바구니 방문 시 회원 항목과 합산. 인증·사이트·최신 재고 확인. 서버에 항목별 처리 기록을 남겨 재시도/동시 요청 중복 방지. 재고 부족 시 실패한 묶음을 보존하여 수량 수정/삭제 후 재시도. |
| 주문서 임시저장 | 같은 탭에 배송정보 30분 보관, 복원 및 직접 지우기. 인증 완료와 동의 상태는 보관하지 않음. 결제 확인 성공 후 임시정보와 구매한 비회원 항목만 정리. |
| 옵션·수량 편집 | 주문서 안에서 변경/적용/취소. 적용 전 결제 차단, 현재 판매 기간·재고·가격 확인 후 배송비/설치비 재견적. 단일상품 주문도 같은 주문서 사용. |
| 출고 예정일 | 기존 관리자 expected_ship_date 사용. 상품 상세와 주문서에 표시. 미등록/지난 날짜는 ‘출고 일정 확인 중’. 도착일을 임의 추정하지 않음. |
| 화면 내 주소검색 | Kakao 공식 embed 방식. 별도 팝업 없이 입력 폼 안에서 검색. 실패/지연 안내와 재시도, 선택 완료 시 닫기. |

## 유지한 기준
- 주문 승인 전 서버의 금액·재고·사이트·비전시 링크 검증 유지.
- 비전시 링크 상품은 일반 장바구니로 합치지 않고 원래 전용 링크 구매 경로 유지.
- 배송지 우편번호는 주소검색으로 확보. 관리자 추가 배송지역 우편번호를 다시 필수로 만들지 않음.
- 합치기 COMMIT 응답이 유실된 경우 성공/실패를 단정하지 않고 같은 항목으로 재시도. DB 중복 처리 기록으로 추가 합산 차단.
- DB 조회 실패를 상품 품절로 처리하지 않고 재시도 오류로 구분.
