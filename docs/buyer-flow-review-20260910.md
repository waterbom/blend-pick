# 구매 흐름 보완 · 2026-09-10

## 반영한 내용
- 상품 상세의 배송/환불 안내가 상품 상단과 같은 shippingLabel을 사용한다. 기본 안내에 무료배송을 단정하지 않는다.
- 장바구니는 모든 응답이 성공했을 때만 완료 표시한다. 실패/통신 오류 시 자동 재시도하지 않는다. 부분 성공 시 담긴 옵션 수를 안내하고 다음 요청에서는 성공한 옵션을 제외한다.
- 401 로그인 이동에 현재 상품 경로와 query(인플루언서 등)를 유지한다. 같은 탭의 선택 옵션/수량을 30분 이내 한 번 복원하고 현재 재고/활성 상태로 제한한다. 자동으로 재담지는 않는다.
- 추가상품이 선택된 장바구니 요청은 누락 저장하지 않고 바로 구매를 안내한다. 기존 바로 구매 경로가 추가상품 구성을 전달한다.
- 헤더 로그인도 현재 페이지로 돌아오도록 연결한다. 이메일 로그인 return URL은 외부 주소/백슬래시/개행을 거부한다.
- 산지픽 신상품 전체 보기는 /products 또는 프리뷰 경로 /sanji/products로 이동한다.
- 산지픽 상세 가격 아래 구매 가능한 옵션의 구성/등급/가격 비교를 표시한다. 실제 상품명·등급·가격 DB 값은 수정하지 않았다. 상품 제목의 포괄적인 품질 문구 자체는 운영자가 등록 정보를 확인할 필요가 있다.
- 주문서 옵션명이 이름/값에 동일하게 저장된 경우 한 번만 표시한다.
- 주문서 문서 제목은 호스트별 브랜드로 생성하고 검색 색인을 차단한다.

- tests/buyer-flow.cjs: 18개 통과. 실제 ProductDetail 이벤트를 hook 상태로 구동하는 시뮬레이션 포함.
- 기존 payment-launch, shipping-fees, storefront-site, sanjipick-mypage 테스트 통과. API/인증/배송비/사이트 분리 검증은 운영 DB가 아닌 mock 또는 격리 PostgreSQL 사용.
- TypeScript 검사와 npm run build -- --webpack 성공.
- git diff --check 통과.
- 운영 주문서를 브라우저로 재확인했다. 수정본 로컬 UI는 브라우저의 ERR_BLOCKED_BY_CLIENT로 열 수 없었다. 수정된 화면의 실제 브라우저 전체 E2E 검증 완료로 해석하면 안 된다.
- 임시 격리 화면과 dev 서버는 제거/종료했다. 실제 결제·SMS·주문 생성·환불·운영 DB 변경·배포 없음.
