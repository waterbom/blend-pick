# JS하우스 예약 운영

연남동 JS하우스 예약 페이지. 블랜드픽에서 파생된 독립 페이지로, 블랜드픽 공통 헤더 없이 자체 디자인을 씁니다.

- 고객 페이지: `/hotel/jshouse` (예약 조회는 `/hotel/jshouse#lookup`)
- 관리자: 관리자 → 공구 운영 → JS하우스 예약 (`/admin/jshouse`)
- 노출 위치: 블랜드픽 메인 "이런 하루도, 공구로" 첫 카드, `/hotel` 배너, 사이트맵

## 예약 흐름

온라인 결제는 연결되어 있지 않습니다. 신청 → 운영자 확정 방식입니다.

1. 고객이 달력에서 체크인·체크아웃을 고르고 이름·휴대폰 번호로 신청합니다.
2. 신청 즉시 그 날짜가 잡힙니다. 하루에 한 팀만 받습니다(`jshouse_nights.day` 유일 제약).
3. 운영자가 관리자 화면에서 확정 또는 거절합니다. 거절·취소하면 날짜가 다시 열립니다.
4. 단계마다 고객과 운영자에게 문자가 갑니다. 문자 발송이 실패해도 예약 처리는 그대로 진행되고 기록에 남습니다.

고객은 예약번호(`JS-XXXXXX`)와 휴대폰 번호로 조회·취소합니다. 확정 전에는 바로 취소되고, 확정 후에는 취소 요청으로 접수되어 운영자가 처리합니다.

## 오픈 전에 입력할 값

관리자 → JS하우스 예약 → 기본 설정에서 넣습니다. 비워 두면 페이지에 "예약 확정 시 안내"로 표시됩니다.

- 평일·주말(금·토) 1박 요금. 특정 날짜는 달력에서 따로 덮어쓸 수 있습니다.
- 체크인·체크아웃 시간, 최대 인원(기본 4명)
- 주소, 지도 링크, 오시는 길, 주차 안내
- 이용 안내·공지 문구
- 신청 알림을 받을 운영자 휴대폰 번호

요금이 하나라도 비어 있는 날짜가 포함되면 합계 대신 "확정 시 안내"로 보여 줍니다. 임의의 요금·환불 규정은 코드에 넣지 않았습니다.

## 사진 추가

1. `public/hotel/jshouse/`에 `이름.webp`(세로 952×1269 권장)와 `이름-sm.webp`(너비 520)를 넣습니다.
2. `components/jshouse/content.ts`의 `SPACES`에 항목을 추가합니다. 둘러보기·크게 보기에 자동으로 들어갑니다.

## 코드 위치

| 역할 | 파일 |
|---|---|
| 페이지 | `app/hotel/jshouse/page.tsx`, `components/jshouse/*` |
| 예약 규칙·날짜 잠금 | `lib/jshouse-core.cjs` |
| 문자 문구 | `lib/jshouse-messages.cjs` |
| API | `app/api/jshouse/route.ts`, `app/api/admin/jshouse/route.ts` |
| 테이블 | `scripts/jshouse.sql` (배포 때 `scripts/prepare-jshouse.cjs`가 실행, 기존 데이터 유지) |
| 테스트 | `npm run test:jshouse` |

## 카드 결제를 붙이려면

요금과 취소·환불 규정이 확정되어야 합니다. 확정되면 단궁 예약(`docs/dangung-booking.md`)과 같은 방식으로 토스 결제를 연결할 수 있습니다.
