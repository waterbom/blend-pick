# JS하우스 예약 운영

연남동 JS하우스 예약 페이지. 블랜드픽에서 파생된 독립 페이지로, 블랜드픽 공통 헤더 없이 자체 디자인을 씁니다.

- 고객 페이지: `/hotel/jshouse` (예약 조회는 `/hotel/jshouse#lookup`, 결제 결과는 `/hotel/jshouse/result`)
- 관리자: 관리자 → 공구 운영 → JS하우스 예약 (`/admin/jshouse`)
- 노출 위치: 블랜드픽 메인 "이런 하루도, 공구로" 첫 카드, `/hotel` 배너, 사이트맵

## 예약 흐름

예약 방식은 두 가지이고, 손님이 고른 일정에 따라 서버가 정합니다.

### 카드 결제 (블랜드픽과 같은 토스 결제 과정)

요금이 모두 정해진 일정이고 아래 조건이 갖춰지면 결제로 받습니다.

- 기본 설정의 ‘카드 결제 받기’가 켜져 있음 (기본값 켜짐)
- 취소·환불 규정이 20자 이상 입력되어 있음
- 서버에 토스 실결제 키가 있음 (블랜드픽·단궁과 같은 키)

1. 손님이 날짜를 고르고 예약자 정보를 적은 뒤 취소·환불 규정에 동의합니다.
2. 서버가 금액과 규정을 다시 확인하고 날짜를 15분 동안 잡습니다.
3. 토스 결제창에서 카드로 결제하면 결과 화면(`/hotel/jshouse/result`)에서 서버가 승인하고 예약이 바로 확정됩니다. 확정 문자가 손님과 운영자에게 갑니다.
4. 결제창을 닫거나 결제에 실패하면 날짜가 바로 다시 열립니다. 15분 안에 돌아오지 않아도 자동으로 열립니다.

취소는 손님이 예약 조회에서 요청하고, 운영자가 관리자 화면의 ‘환불 취소’에서 환불 금액을 정합니다. 손님이 결제할 때 동의한 규정이 예약마다 저장되어 있으니 그 내용을 보고 금액을 넣습니다. 0원을 넣으면 환불 없이 취소됩니다.

결제 승인이나 환불 응답을 받지 못하면 예약이 ‘결제 확인 중’ 또는 ‘환불 확인 중’으로 남습니다. 이때는 날짜를 자동으로 풀지 않습니다. 관리자 화면의 ‘결제 상태 다시 확인’을 누르면 토스 기록과 맞춰 정리합니다. 손님이 결과 화면이나 예약 조회를 다시 열어도 같은 확인이 실행됩니다.

### 예약 신청 (결제 없음)

요금이 없는 날짜가 섞여 있거나 카드 결제가 꺼져 있으면 신청으로 받습니다.

1. 고객이 달력에서 체크인·체크아웃을 고르고 이름·휴대폰 번호로 신청합니다.
2. 신청 즉시 그 날짜가 잡힙니다.
3. 운영자가 관리자 화면에서 확정 또는 거절합니다. 거절·취소하면 날짜가 다시 열립니다.

### 공통

- 하루에 한 팀만 받습니다(`jshouse_nights.day` 유일 제약).
- 단계마다 고객과 운영자에게 문자가 갑니다. 문자 발송이 실패해도 예약 처리는 그대로 진행되고 기록에 남습니다.
- 고객은 예약번호(`JS-XXXXXX`)와 휴대폰 번호로 조회합니다. 확정 전 신청은 바로 취소되고, 확정된 예약은 취소 요청으로 접수됩니다.

## 오픈 전에 입력할 값

관리자 → JS하우스 예약 → 기본 설정에서 넣습니다. 비워 두면 페이지에 "예약 확정 시 안내"로 표시됩니다.

- 평일·주말(금·토) 1박 요금. 특정 날짜는 달력에서 따로 덮어쓸 수 있습니다.
- 취소·환불 규정. 카드 결제를 받으려면 꼭 필요합니다. ‘단궁 예약의 환불 규정 불러오기’로 불러온 뒤 JS하우스에 맞게 고쳐 쓸 수 있습니다.
- 체크인·체크아웃 시간, 최대 인원(기본 4명)
- 주소, 지도 링크, 오시는 길, 주차 안내
- 이용 안내·공지 문구
- 신청·결제 알림을 받을 운영자 휴대폰 번호

요금이 하나라도 비어 있는 날짜가 포함되면 합계 대신 "확정 시 안내"로 보여 주고 신청으로 받습니다. 임의의 요금·환불 규정은 코드에 넣지 않았습니다.

## 사진 추가

1. `public/hotel/jshouse/`에 `이름.webp`(세로 952×1269 권장)와 `이름-sm.webp`(너비 520)를 넣습니다.
2. `components/jshouse/content.ts`의 `SPACES`에 항목을 추가합니다. 둘러보기·크게 보기에 자동으로 들어갑니다.
