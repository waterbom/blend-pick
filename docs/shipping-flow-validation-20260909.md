## 최종 수정 및 재검증 완료

앞서 기록한 3건은 모두 수정 완료. 운영 배포 전 로컬 검토본입니다.

1. 파일 선택 즉시 기존 송장과 결과를 무효화. 읽는 동안 제출할 데이터가 없으며, 실패 시 이전 데이터가 복원되지 않음. 파일명 표시와 선택 순서 식별자를 추가하여 느린 이전 파일이 최신 파일을 덮어쓰지 못하도록 처리.
2. CSV 파서를 인용부호를 처리하는 방식으로 변경. 쉼표·여러 줄 메모·이스케이프된 따옴표·BOM·CRLF·송장 앞자리 0 보존. 닫히지 않거나 잘못 배치된 따옴표는 명시적 오류.
3. 교환·반품 패널을 공유 주문 현황 갱신에 연결. 새 요청이 주기적 갱신에 반영되며, 처리 중에는 갱신을 미루고 처리 종료 후 재조회. 화면을 재마운트하지 않아 신청별 조회 상태 유지.
