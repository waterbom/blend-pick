# 블랜드픽 AI 도우미 연결

기존 도우미 창에서 최근 4번의 문답을 참고하는 텍스트 AI 대화와 점진적 답변 표시를 지원한다. 서버가 OpenAI Responses API를 호출하며 브라우저에는 API 키를 전달하지 않는다. 기본 상태는 기존 FAQ 안내다. 이 변경만 배포해도 AI 호출이나 비용이 발생하지 않는다.

## 활성화 전 설정

운영자가 서버의 기존 비공개 환경 설정에 다음 값을 등록한다. 실제 키를 채팅, PR, 저장소 또는 NEXT_PUBLIC 변수에 넣지 않는다.

| 변수 | 설정 |
| --- | --- |
| OPENAI_API_KEY | 사용량 결제가 설정된 OpenAI 프로젝트의 API 키 |
| OPENAI_CHAT_MODEL | 해당 프로젝트에서 사용 가능한 Responses 텍스트 모델 ID |
| BLEND_AI_ENABLED | 활성화를 승인한 뒤에만 true |
| BLEND_AI_DAILY_REQUEST_LIMIT | 프로세스당 하루 요청 상한, 기본 300, 최대 2000 |

모델은 임의의 고가 기본값을 선택하지 않도록 필수 설정이다. 실제 선택한 모델로 한국어 응답 품질과 응답 제한(900 출력 토큰)을 확인한 뒤 활성화한다. reasoning에 많은 토큰을 쓰는 모델은 이 제한에서 미완료 응답이 발생할 수 있다.

비용과 외부 AI 처리가 새로 추가되므로 사용자에게 활성화 범위를 확인한 뒤 운영 설정을 적용한다. 일반 FAQ 수정과 다르게 자동 활성화하지 않는다. 서버 환경 변경 후 기존 앱 재시작 절차를 따른다. 중단할 때는 BLEND_AI_ENABLED=false로 변경하고 재시작하면 기본 FAQ로 돌아간다.

## 답변 범위

- 질문마다 공개 블랜드픽 상품의 가격, 판매 일정, 판매 상태와 관련 상품의 공개 안내를 읽는다. 산지픽·비공개·비활성·비밀링크 전용 상품과 개인 주문 데이터는 포함하지 않는다.
- 최대 80개 상품 목록, 관련 상세 최대 4개로 참고 자료를 제한한다. 상품이 목록에 없다고 판매 여부를 단정하지 않는다.
- 숙박 판매기간과 실제 객실/이용일 재고를 구분한다. 객실 재고 및 개별 예약 조회는 연결하지 않는다.
- 주문·예약·결제·취소·환불은 실행하지 않는다. 기존 인증 조회 화면과 카카오 상담으로 안내한다.
- 링크는 서버가 공개 자료에서 구성한 상품 경로 및 기존 FAQ 링크만 제공한다. 모델의 텍스트는 HTML이나 링크로 실행하지 않는다.

## 처리 및 제한

AI 활성 상태에서는 고객의 질문, 최근 문답과 공개 상품 자료가 OpenAI로 전달되며 UI에 이를 안내한다. 일반적인 전화번호·이메일·개인번호 패턴을 전송 전 가리지만 모든 개인정보 탐지를 보장하지 않는다. 서비스 DB나 애플리케이션 로그에 대화 원문을 기록하지 않고, Responses 요청에 store:false를 사용한다. 이는 제공자의 모든 로그/보존을 없앤다는 의미는 아니다. 운영자는 실제 적용되는 OpenAI 데이터 정책과 사이트 개인정보 안내를 함께 확인해야 한다.

이 API는 블랜드픽 호스트와 동일 출처 JSON 요청만 받는다. 본문 64 KiB, 질문 500자, 최근 이력 포함 12,000자, 답변 4,000자 및 최대 출력 900토큰으로 제한한다. 요청은 30초에 중단하며 창을 닫거나 대화를 초기화하면 클라이언트가 요청을 취소한다. 잘린 응답·연결 실패는 완료로 표시하지 않고 기본 안내로 대체한다.

프로세스당 동시 요청 3개, IP당 분당 10개, 하루 기본 300개를 허용한다. nginx가 덧붙인 마지막 X-Forwarded-For 값을 사용하고 원본 IP를 저장하지 않는다. 메모리 제한은 재시작 시 초기화되며 여러 프로세스에서 공유되지 않는다. 금액 상한이 아니므로 OpenAI 프로젝트의 사용량 제한/알림도 따로 설정한다. 다중 인스턴스로 확장하면 공유된 제한 저장소로 교체해야 한다.

## 검증과 배포 순서

1. npm run test:buyer 및 CI_DB_FREE_BUILD=true npm run build -- --webpack을 통과시킨다. 테스트는 API/DB 모킹으로 진행하며 유료 호출을 하지 않는다.
2. API 키와 모델을 비공개 환경에 설정한 뒤, 승인받은 테스트 환경에서 실제 모델 연결을 검증한다. 현재 변경에는 유료 호출 실검증 결과가 포함되지 않는다.
3. 상품명을 물은 뒤 '그럼 언제 마감돼?', 숙박 취소, 교육 제안, 알 수 없는 상품, 연결 중단, 창 닫기, 한글 입력을 확인한다. 실제 주문·취소나 문의 전송은 필요하지 않다.
4. 활성화 승인 후 운영 배포·설정을 반영하고 GET /api/help/chat의 enabled 및 작은 실제 답변 1회를 확인한다. nginx에는 X-Accel-Buffering:no로 점진적 전송을 요청하며 실제 운영 프록시에서 출력이 모이지 않는지 확인한다.
