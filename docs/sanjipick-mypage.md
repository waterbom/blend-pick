## 변경

산지픽 `/mypage`는 `/sanji/mypage`의 독립 화면을 사용한다. `/sanji` 미리보기에서 공용 `/mypage`로 들어오는 경우에도 산지픽 화면으로 분기한다. 호텔 예약, OS 구독, 인플루언서 대시보드는 산지픽 마이페이지에 표시하지 않는다. Shop의 호텔 예약과 OS 구독 화면은 유지한다.

회원 주문, 비회원 주문 조회, 교환·반품 폼, 취소·반품 API, 리뷰 구매 자격을 기존 `orders.site` 값으로 분리한다. 요청 사이트 외의 주문을 고객 API에서 조회하거나 처리하지 않는다. 상품 링크는 산지픽 `/p/:id`, 후기 작성은 산지픽 마이페이지 하위 경로로 연결한다. 주문 조회 실패는 빈 주문 내역과 구분한다.

로그아웃은 산지픽 도메인 또는 `/sanji` 미리보기 홈으로 돌아간다. 회원 계정과 인증 시스템은 기존처럼 공유한다. 따라서 회원탈퇴는 두 서비스의 계정에 영향을 준다는 내용을 산지픽 탈퇴 확인창에 표시한다.

## 운영 반영 시 유의할 기존 구조

`orders.site` 마이그레이션이 적용되어 있어야 한다. 배포 워크플로가 이미 해당 마이그레이션을 실행하도록 구성되어 있다. 기존 주문의 사이트 값을 이번 수정에서 임의로 변경하지 않았다.

카카오 OAuth 콜백은 기존 코드에서 shop 호스트로 고정되어 있다. 산지픽 마이페이지의 로그인 복귀 경로는 `/sanji/mypage`로 지정해 이 콜백을 거쳐도 산지픽 화면을 유지한다. OAuth 도메인 및 계정 DB 자체를 별도로 분리하는 작업은 포함하지 않는다. 실제 카카오 로그인 및 운영 주문 흐름은 배포 허가 후 별도 확인이 필요하다.
