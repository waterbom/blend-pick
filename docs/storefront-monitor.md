# 사이트 자동 점검 검토본

기준 작업본: f071b18 (`오늘 처리할 일` 반영 커밋). 운영 최신 상태는 다음 배포 직전에 다시 확인한다.
이번 작업은 독립된 점검 스크립트·보고서·수동 실행 워크플로이며 앱 화면, DB, 배송 처리 및 배포 워크플로를 변경하지 않는다. 원격 푸시·배포·정기 실행은 하지 않았다.

## 실행 및 결과

- 격리 검증: `node --test tests/storefront-monitor.cjs`
- 설명용 미리보기: `node scripts/check-storefront.cjs --example --output-dir monitor-example`
- 공개 응답 1회 점검: `node scripts/check-storefront.cjs --output-dir monitor-output`
- 예시 모드는 네트워크 요청 없이 네 가지 판정과 재시도 기록을 보여준다.
- 결과: `report.html`(사이트·판정 필터, 조치 안내), `results.json`(구조화 기록), `summary.md`(요약).
- 종료 코드: 0=실패 없음(주의·미검사 가능), 1=실패 존재, 2=실행 자체 미완료. 예시 실행은 장애 예시를 포함해도 0.
- Actions에서는 단계 요약과 결과 파일 14일 보관 설정. 실패는 작업 실패로 표시된다. 별도의 메일·Slack·문자 발송 기능은 없다.

## 점검 항목

| 대상 | 기준 | 한계 |
|---|---|---|
| 두 사이트 메인·상품 목록 | HTTP 200, HTML 구조·제목, 알려진 오류 화면, 예시 상품 링크, 검색 제외 설정 | 클라이언트 렌더링·API 내부 성공·사이트별 상품 소속은 미확인 |
| 로그인 진입 | 로그인 HTML 응답 | 실제 로그인 성공·일반 고객의 관리자 권한 여부는 미확인 |
| 상품 상세 | 메인·목록·사이트맵에서 추출한 안전한 동일 도메인 상품 경로 최대 3개 | 전체 상품·모든 링크·목록/상세 판매 상태 일치 검사는 아님. 링크 없으면 미검사 |
| robots.txt | 현재 도메인 사이트맵 선언, 일반 봇 루트 차단 기본 규칙 | 모든 봇별 세부 규칙 해석은 아님 |
| sitemap.xml | urlset 기본 구조, 주소 존재·현재 도메인·예시 경로 제외 | 완전한 XML 스키마 검사·검색엔진 등록/색인 확인은 아님 |
| 관리자 화면 | 401/403 또는 동일 도메인 /login 리다이렉트 | 비로그인 기준, 전체 관리자 경로 검사는 아님 |
| 관리자 API | `/api/admin/returns?kind=return`이 401/403 | 본문 수집 안 함. 반환값·실제 업무 데이터 검증 안 함 |

## 판정과 재확인

- 실패: HTTP 오류·연결 실패·시간 초과·잘못된 이동·HTML 오류·관리자 차단 실패.
- 주의: 3초 이상 응답, 재확인 성공, 제목/검색 설정 이상, 예시 링크, 5MiB 초과 응답으로 내용 검사 미완료.
- 미검사: 상품 표본을 찾지 못함. 판매 준비 표시 자체는 장애가 아니다.
- 연결 실패·시간 초과·429·5xx 응답만 1초 후 1회 재확인. 요청당 15초, 최대 3회 리다이렉트, 같은 도메인의 같은 경로만 따라간다.
- 재확인 성공은 이번 실행 안에서의 회복이다. 이전 회차 장애와 비교한 복구 판정은 아니다.
- JSON/HTML에는 응답 본문·인증정보·주문/고객 정보를 넣지 않는다.

## 활성화 전 검토 및 후속 범위

1. 사용자가 자동 점검 배포/활성화를 지시하면 최신 main과 충돌 여부 및 격리 검증을 다시 확인한다.
2. 워크플로 수동 실행 1회로 실제 도메인 응답과 오탐을 확인한다. 외부 검사자의 네트워크 문제를 서비스 장애로 단정하지 않는다.
3. 정기 실행을 원하면 주석 처리된 cron `17,47 * * * *`를 활성화한다. 약 30분 간격이며 정시 실행 보장은 없다.
4. 배포 직후 점검 연동은 기존 배포 작업을 수정해야 하므로 이번에 넣지 않았다.
5. 실행 누락 감시, 회차 간 장애 지속/복구 이력, 알림 중복 방지·수신 대상 연결은 후속 구현이다. 현재 파일 보관은 이력 비교 기능이 아니다.
6. 실제 결제는 테스트 환경에서 별도 검증. 기존 배송 자동 조회의 건별 실패·문자 전달 성공 여부도 이 공개 사이트 점검 범위에 포함되지 않는다.
7. 자동 복구·롤백·주문 변경·문자 발송은 수행하지 않는다.
