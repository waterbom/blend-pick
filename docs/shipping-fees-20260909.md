# 배송비 수정과 배송 자동화 범위

## 적용 규칙

- 무료/고정/조건부무료/건별 배송은 기존 뜻을 유지. 건별 배송은 1개 무료, 2개째부터 추가.
- 상품 옵션 수량은 상품별로 합산. 무료배송 기준은 해당 상품의 본품·옵션 금액 기준이며 추가상품·설치비는 기준금액에서 제외.
- 고정 배송비는 공급사명·출고지·택배사가 모두 같은 상품끼리 가장 큰 금액으로 묶음. 하나라도 미지정이면 상품별 분리. 건별 요금은 묶음 내에서 상품별 추가 합산.
- 도서산간 추가비는 관리자에 설정한 5자리 우편번호/우편번호 범위에만 적용. 업체별 계약 지역을 임의 추정하지 않음. 같은 배송 묶음에서는 지역 추가비 중 큰 금액을 한 번 부과.
- 추가비가 있는데 적용 지역을 설정하지 않은 상품은 계산 실패를 표시하고 결제를 차단. 설정이 정상인 상품과 기존 주문에는 영향 없음.
- 설치비는 본품 수량 × 개당 설치비. 별도의 주문 항목으로 저장. 배송비 차감 취소에서 설치비까지 배송비로 공제하지 않음. 설치 서비스의 공급원가는 미확정으로 남겨 실제 이익을 과대 확정하지 않음. 설치비에는 인플루언서 수수료 0 적용.

## 결제 일치

- 단품·다중 옵션·장바구니는 공통 서버 견적을 사용. DB 가격, 판매 상태, 사이트, 비전시 링크 기간도 확인.
- 배송지 선택 후 지역 추가비·설치비·총액 표시. 주소 변경은 이전 견적을 무효화.
- 조회 실패나 진행 중에는 결제 불가. 결제 직전 재조회에서 금액이 달라지면 새 금액을 확인 후 다시 결제.
- 승인 전 같은 계산을 다시 수행하여 배송비·설치비 누락을 차단.
- 상세에서 바로 구입한 임시 행 ID와 회원 장바구니 ID를 분리. 실제 장바구니 삭제에는 기존 소유권 검증 유지.

## 배송 자동화

| 단계 | 현재 처리 |
|---|---|
| 배송비 계산 | 주소 선택·결제 직전·승인 전 자동 계산 |
| 발주 대상 분류 | 결제·배송지·상품·환불 상태 기준 자동 분류 |
| 발주 확정 | 관리자 확인 후 서버 재검사·이력 저장·배송준비 전환 |
| 공급사별 파일 | 공급사·출고일 정렬, 확정 당시 파일 재다운로드 |
| 공급사 전송·회신 | 연동 방식과 수신처 설정 필요. 자동 전송 미실행 |
| 송장 | 기존 송장 업로드·누락 보완 기능 사용 |
| 배송 추적 | 기존 정기 배송 조회 유지 |
| 예외 | 미출고·송장 누락 등 오늘 처리할 일에서 확인 |

## 검증

신규 배송비 검증 13개, 기존 관리자 검증 73개, 업무 개편 검증 14개, 통계·결제 진입 검증 36개 통과.
실제 단품·장바구니 컴포넌트에 예시 응답을 연결하여 주소 변경, 설치비, 조회 실패 차단, 재시도, 결제 SDK와 저장 금액 일치를 확인. SDK와 외부 결제는 모의 호출만 사용.
배포 시 shipping-fees.sql을 기존 마이그레이션 트랜잭션에 적용. check-shipping-config.cjs가 활성 상품의 누락 설정 건수를 읽기 전용으로 출력.
