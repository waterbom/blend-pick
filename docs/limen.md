# LIMEN(리멘) 예약 운영

연남동 프라이빗 스테이 LIMEN의 예약 페이지. 블랜드픽에서 파생된 독립 페이지로, 블랜드픽 공통 헤더 없이 자체 디자인을 씁니다.
브랜드명 확정 전에는 'JS하우스'라는 작업명을 썼습니다. 예전 주소(`/hotel/jshouse`, `/admin/jshouse`)는 새 주소로 자동 이동합니다.

- 고객 페이지: `/hotel/limen` (예약 조회는 `/hotel/limen#lookup`, 결제 결과는 `/hotel/limen/result`)
- 관리자: 관리자 → 공구 운영 → LIMEN 예약 (`/admin/limen`)
- 노출 위치: 블랜드픽 메인 "이런 하루도, 공구로" 첫 카드, `/hotel` 배너, 사이트맵

## 객실과 요금

숙소가 보낸 요금 안내(2026-11)를 기본값으로 넣었습니다. 관리자 → 4. 객실 요금표에서 고칠 수 있습니다.

| 구분 | 원룸 · 2인 | 투룸 · 4인 |
|---|---|---|
| 주중 (일–목) | 200,000원 | 350,000원 |
| 금요일 | 230,000원 | 380,000원 |
| 토요일 | 250,000원 | 400,000원 |
| 준성수기 | 270,000원 | 420,000원 |
| 극성수기 | 300,000원 | 450,000원 |

- 기준 인원이 곧 최대 인원입니다. 인원 추가는 받지 않습니다.
- 두 객실은 서로 다른 공간으로 보고 날짜를 따로 잡습니다. 같은 객실의 같은 밤은 한 팀만 예약됩니다.
- 준성수기·극성수기는 기간이 정해져 있지 않습니다. 관리자 블럭표에서 날짜를 골라 시즌으로 지정한 날에만 그 요금이 적용됩니다.
- 프로모션·공동구매처럼 요금표와 다른 날은 블럭표에서 '그날만의 요금'을 지정합니다. 지정 요금 → 시즌 → 요일 순서로 적용됩니다.
- 연박 요금은 머무는 날짜의 1박 요금을 더한 금액입니다. 따로 할인은 없습니다.
- 요금 칸을 비우면 그 요일·시즌은 요금 없이 신청으로만 받습니다.

## 블럭표

관리자 → 2. 블럭표가 객실×날짜 예약 현황표입니다. 한 달씩 보이고, 칸마다 예약자(확정·진행 중)·닫힘·시즌·그날의 요금이 표시됩니다.
칸을 눌러 시작일과 종료일을 고른 뒤 예약 닫기·다시 열기, 준성수기·극성수기 지정, 그날만의 요금 지정을 합니다. 누른 항목만 바뀌고 나머지 설정은 그대로 남습니다.
전화나 다른 플랫폼에서 잡힌 예약은 '3. 예약 직접 등록'으로 넣거나 그 날짜를 닫아 두면 손님 달력에 마감으로 보입니다.

## 예약 흐름

예약 방식은 두 가지이고, 손님이 고른 일정에 따라 서버가 정합니다.

### 카드 결제 (블랜드픽과 같은 토스 결제 과정)

요금이 모두 정해진 일정이고 아래 조건이 갖춰지면 결제로 받습니다.

- 기본 설정의 '카드 결제 받기'가 켜져 있음 (기본값 켜짐)
- 취소·환불 규정이 20자 이상 입력되어 있음
- 서버에 토스 실결제 키가 있음 (블랜드픽·단궁과 같은 키)

1. 손님이 객실과 날짜를 고르고 예약자 정보를 적은 뒤 취소·환불 규정에 동의합니다.
2. 서버가 금액과 규정을 다시 확인하고 그 객실의 날짜를 15분 동안 잡습니다.
3. 토스 결제창에서 카드로 결제하면 결과 화면(`/hotel/limen/result`)에서 서버가 승인하고 예약이 바로 확정됩니다. 확정 문자가 손님과 운영자에게 갑니다.
4. 결제창을 닫거나 결제에 실패하면 날짜가 바로 다시 열립니다. 15분 안에 돌아오지 않아도 자동으로 열립니다.

취소는 손님이 예약 조회에서 요청하고, 운영자가 관리자 화면의 '환불 취소'에서 환불 금액을 정합니다. 손님이 결제할 때 동의한 규정이 예약마다 저장되어 있으니 그 내용을 보고 금액을 넣습니다. 0원을 넣으면 환불 없이 취소됩니다.

결제 승인이나 환불 응답을 받지 못하면 예약이 '결제 확인 중' 또는 '환불 확인 중'으로 남습니다. 이때는 날짜를 자동으로 풀지 않습니다. 관리자 화면의 '결제 상태 다시 확인'을 누르면 토스 기록과 맞춰 정리합니다.

### 예약 신청 (결제 없음)

요금이 없는 날짜가 섞여 있거나 카드 결제가 꺼져 있으면 신청으로 받습니다. 신청 즉시 그 객실의 날짜가 잡히고, 운영자가 확정 또는 거절합니다. 거절·취소하면 날짜가 다시 열립니다.

### 공통

- 단계마다 고객과 운영자에게 문자가 갑니다. 문자 발송이 실패해도 예약 처리는 그대로 진행되고 기록에 남습니다.
- 고객은 예약번호(`LM-XXXXXX`)와 휴대폰 번호로 조회합니다. 브랜드명 확정 전에 발급한 `JS-` 번호도 계속 조회됩니다.

## 아직 정해지지 않은 것

- 주소, 지도 링크, 오시는 길, 주차, 체크인·체크아웃 시간: 관리자 기본 설정에서 넣습니다. 비워 두면 "예약 확정 시 안내"로 표시됩니다.
- 취소·환불 규정: 넣어야 카드 결제가 켜집니다.
- 준성수기·극성수기 적용 기간: 블럭표에서 지정합니다.
- 브랜드 로고: 받기 전까지 글자 워드마크(LIMEN)와 문 모양 표식을 씁니다. 파일을 받으면 `components/limen/Sections.tsx`의 `Mark`와 워드마크를 바꿉니다.

## 사진 추가

지금 사진은 원룸 4장(가벽이 있는 방·침대·식탁·주방), 투룸 5장(트윈룸·침실·주방·드레스룸·욕실)입니다.

1. `public/hotel/limen/`에 `이름.webp`(세로 952×1269 권장)와 `이름-sm.webp`(너비 520)를 넣습니다. 원룸 사진은 이름 앞에 `one-`을 붙였습니다.
2. `components/limen/content.ts`의 `SPACES_BY_ROOM`에서 해당 객실에 항목을 추가합니다. 둘러보기·크게 보기에 자동으로 들어갑니다.
3. 객실 카드의 대표 사진은 같은 파일의 `ROOMS`에서 바꿉니다.

## 디자인

- 서체는 Pretendard 한 가지입니다. `components/limen/fonts/`에 분할 글꼴을 내장했고(SIL OFL 1.1), 화면에 쓰인 글자 묶음만 내려받습니다.
- 색은 밝은 벽 색과 잉크색 두 가지에 오크색 하나만 포인트로 씁니다. 값은 `components/limen/limen.css` 맨 위에 있습니다.
- 사진은 문 모양 틀에 담고, 두 문짝이 양옆으로 열리며 드러납니다. '문을 지나는 장면'은 스크롤에 맞춰 문이 열리고 주변이 어두워집니다.
- 브랜드 문구는 숙소가 보낸 브랜드 문서의 문장을 그대로 옮겼습니다(`components/limen/content.ts`).

## 코드 위치

| 역할 | 파일 |
|---|---|
| 페이지 | `app/hotel/limen/page.tsx`, `components/limen/*` |
| 결제 결과 화면 | `app/hotel/limen/result/page.tsx`, `components/limen/Result.tsx` |
| 예약 규칙·객실별 날짜 잠금·요금 계산·결제 상태 | `lib/limen-core.cjs` |
| 토스 결제 API 호출 | `lib/toss-api.ts`, `lib/limen-server.ts` |
| 문자 문구 | `lib/limen-messages.cjs` |
| API | `app/api/limen/route.ts`, `app/api/admin/limen/route.ts` |
| 테이블 | `scripts/limen.sql` (배포 때 `scripts/prepare-limen.cjs`가 실행, 기존 데이터 유지) |
| 테스트 | `npm run test:limen` |

테이블 이름은 `jshouse_*` 그대로입니다. 운영 데이터를 건드리지 않으려고 이름을 바꾸지 않았습니다. 객실 구분이 없던 때의 예약과 날짜 설정은 모두 투룸으로 옮겨집니다.
